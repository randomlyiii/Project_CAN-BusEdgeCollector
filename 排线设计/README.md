## 核心接线速查

### 主站
| 模块 | 关键引脚 | 注意事项 |
|------|----------|----------|
| W5500 以太网 | RST=PC15, SCS=PA4, SPI=PA5/PA6/PA7 | **双 GND 都必须接地**，3.3V 外接独立供电 |
| TJA1050 CAN | TXD=PA12, RXD=PA11 | VCC=5V, GND 与从站 TJA1050 共地 |
| OLED | SCL=PB8, SDA=PB9 | I2C 0x78, 开漏模式 |
| ST-Link | SWDIO/SWCLK/GND | **只接三根线，严禁接 3.3V** |

### 从站
| 模块 | 关键引脚 | 注意事项 |
|------|----------|----------|
| TJA1050 CAN | TXD=PA12, RXD=PA11 | CANH/CANL/GND 三线与主站直连 |
| DHT11 | DATA=PB11 | 模块已内置上拉 |
| OLED | SCL=PB8, SDA=PB9 | 同主站 |
| KEY1/KEY2 | PA0→GND, PA1→GND | 内部上拉，按下低电平 |

### CAN 总线
- **CAN_H ↔ CAN_H, CAN_L ↔ CAN_L, GND ↔ GND**（三线必须全接）
- GND 不接 → TJA1050 共模电压超范围 → 数据错乱
- 短距离 (<30cm) 不接终端电阻；长距离需 120Ω

### W5500 供电
- 模块板载 LDO 质量参差不齐，**不要从 STM32 3.3V 排针取电**
- 使用外接独立 3.3V 供电，或确保模块 LDO 实测 ≥ 3.2V
