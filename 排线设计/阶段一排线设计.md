# 阶段一排线设计

## 一、系统整体接线拓扑

```
┌─────────────────────────────────────────────────────────────┐
│                         PC (上位机)                          │
│                    Modbus TCP / 网络调试                      │
└─────────────────────┬───────────────────────────────────────┘
                      │ 以太网 (RJ45)
                      │
┌─────────────────────┴───────────────────────────────────────┐
│              主站 CanEdgeGateWay_Master                      │
│  ┌──────────────────────────────────────────────────────┐   │
│  │ STM32F103C8T6                    W5500 以太网模块     │   │
│  │                                                      │   │
│  │ OLED(0.78)  CAN收发器  USART1                        │   │
│  │ I2C(软)     ISO1050    PA9/PA10 → USB-TTL → PC       │   │
│  └──────────────────────────────────────────────────────┘   │
└─────────────────────┬───────────────────────────────────────┘
                      │ CAN Bus (CAN_H / CAN_L)
                      │ 120Ω终端电阻 ×2（总线两端）
                      │
┌─────────────────────┴───────────────────────────────────────┐
│              从站 CanEdgeGateWay_Slave                       │
│  ┌──────────────────────────────────────────────────────┐   │
│  │ STM32F103C8T6                                        │   │
│  │                                                      │   │
│  │ OLED(0x78)  CAN收发器  DHT11  KEY1  KEY2  USART1     │   │
│  │ I2C(软)     ISO1050   PB11   PA0    PA1   PA9/PA10   │   │
│  └──────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

> **阶段一扩展**：可挂载多个从站，拓扑为总线型，每个从站分配唯一CAN节点ID（1~254）。

## 二、主站 (Master) 引脚分配

### 2.1 STM32F103C8T6 引脚总表

| 引脚 | 功能 | 连接目标 | 说明 |
|---|---|---|---|
| PA3 | GPIO_Out | W5500_RST | W5500硬件复位 |
| PA4 | GPIO_Out | W5500_SCS | SPI片选（软件控制） |
| PA5 | SPI1_SCK | W5500_SCLK | SPI时钟 |
| PA6 | SPI1_MISO | W5500_MISO | SPI主入从出 |
| PA7 | SPI1_MOSI | W5500_MOSI | SPI主出从入 |
| PA8 | GPIO_Out | — | 预留：LED状态灯 |
| PA9 | USART1_TX | USB-TTL模块 RX | 调试串口发送 |
| PA10 | USART1_RX | USB-TTL模块 TX | 调试串口接收 |
| PA11 | CAN1_RX | CAN收发器 RXD | CAN接收 |
| PA12 | CAN1_TX | CAN收发器 TXD | CAN发送 |
| PB8 | GPIO_Out (OD) | OLED SCL | 软件I2C时钟线 |
| PB9 | GPIO_Out (OD) | OLED SDA | 软件I2C数据线 |
| — | VCC 3.3V | OLED VCC, W5500 V3.3 | 模块供电 |
| — | VCC 5V | CAN收发器 VCC | 隔离电源输入 |
| — | GND | 所有模块共地 | 参考地 |

### 2.2 OLED接线（主站）

```
OLED模块 (0.96寸 I2C, 地址 0x78, 4pin)
┌──────────┐
│ GND ──────────── GND
│ VCC ──────────── 3.3V
│ SCL ──────────── PB8 (STM32)
│ SDA ──────────── PB9 (STM32)
└──────────┘
```

### 2.3 CAN收发器接线（主站）

```
ISO1050 / TJA1050 模块
┌──────────────────┐
│ VCC ──────────────── 5V
│ GND ──────────────── GND
│ TXD ──────────────── PA12 (STM32 CAN_TX)
│ RXD ──────────────── PA11 (STM32 CAN_RX)
│ CANH ─────────────── CAN_H 总线 ────┐
│ CANL ─────────────── CAN_L 总线 ────┤
│ (终端电阻120Ω)                      │
└──────────────────┘                  │
                                      │ 双绞线
   从站CAN收发器 CANH/CANL ───────────┘
```

> **注意**：阶段一只用主站+一个从站时，总线两端各需一个120Ω终端电阻。ISO1050已内置隔离，无需外加光耦；若使用TJA1050方案需外加隔离电路。

### 2.4 W5500以太网模块接线（主站）

```
W5500 模块
┌──────────────────────┐
│ GND ──────────────────── GND
│ V3.3 ──────────────────── 3.3V
│ SCLK ──────────────────── PA5  (SPI1_SCK)
│ MISO ──────────────────── PA6  (SPI1_MISO)
│ MOSI ──────────────────── PA7  (SPI1_MOSI)
│ SCS  ──────────────────── PA4  (GPIO 片选)
│ RST  ──────────────────── PA3  (GPIO 复位)
│ INT  ──────────────────── (暂不接，轮询模式)
│ RJ45 ──────────────────── 网线 → PC / 交换机
└──────────────────────┘
```

### 2.5 调试串口接线（主站）

```
USB-TTL模块 (CH340 / CP2102)
┌─────────────┐
│ TXD ─────────── PA10 (STM32 USART1_RX)
│ RXD ─────────── PA9  (STM32 USART1_TX)
│ GND ─────────── GND
│ VCC ─────────── (不接, STM32独立供电)
│ USB ─────────── PC USB口
└─────────────┘
```

## 三、从站 (Slave) 引脚分配

### 3.1 STM32F103C8T6 引脚总表

| 引脚 | 功能 | 连接目标 | 说明 |
|---|---|---|---|
| PA0 | GPIO_In (上拉) | KEY1 按键 | 故障上报按键，低电平触发 |
| PA1 | GPIO_In (上拉) | KEY2 按键 | 故障恢复按键，低电平触发 |
| PA8 | GPIO_Out | — | 预留：LED状态灯 |
| PA9 | USART1_TX | USB-TTL模块 RX | 调试串口发送 |
| PA10 | USART1_RX | USB-TTL模块 TX | 调试串口接收 |
| PA11 | CAN1_RX | CAN收发器 RXD | CAN接收 |
| PA12 | CAN1_TX | CAN收发器 TXD | CAN发送 |
| PB8 | GPIO_Out (OD) | OLED SCL | 软件I2C时钟线 |
| PB9 | GPIO_Out (OD) | OLED SDA | 软件I2C数据线 |
| PB11 | GPIO_In/Out | DHT11 DATA | 温湿度传感器数据 |
| — | VCC 3.3V | OLED VCC, DHT11 VCC | 模块供电 |
| — | VCC 5V | CAN收发器 VCC | 隔离电源输入 |
| — | GND | 所有模块共地 | 参考地 |

### 3.2 OLED接线（从站）

```
OLED模块 (0.96寸 I2C, 地址 0x78, 4pin)
接线同主站:
  GND → GND
  VCC → 3.3V
  SCL → PB8
  SDA → PB9
```

### 3.3 DHT11温湿度传感器接线（从站）

```
DHT11 模块 (3pin/4pin)
┌──────────────┐
│ VCC ──────────── 3.3V
│ DATA ─────────── PB11 (STM32)
│ GND ──────────── GND
└──────────────┘

注：DATA引脚需外接4.7kΩ上拉电阻至3.3V（部分模块已内置）
```

### 3.4 按键接线（从站）

```
KEY1 (故障上报)            KEY2 (故障恢复)
┌──────────┐              ┌──────────┐
│ 一端 ────── PA0          │ 一端 ────── PA1
│ 另一端 ──── GND           │ 另一端 ──── GND
└──────────┘              └──────────┘

PA0/PA1配置为 GPIO_Mode_IPU（内部上拉输入）
按下 → 低电平 → 触发对应功能
```

### 3.5 CAN收发器接线（从站）

```
与主站接法相同:
  VCC → 5V
  GND → GND
  TXD → PA12
  RXD → PA11
  CANH → CAN_H 总线
  CANL → CAN_L 总线
```

### 3.6 调试串口接线（从站）

```
与主站接线相同:
  USB-TTL TXD → PA10
  USB-TTL RXD → PA9
  USB-TTL GND → GND
```

## 四、CAN总线物理层规范

### 4.1 总线拓扑

```
主站 ────┬──────────────┬── ··· ──┐
         │              │          │
     [120Ω]       从站#1      从站#N    [120Ω]
         │              │          │
        GND            GND        GND
```

- **线缆**：双绞屏蔽线，特性阻抗120Ω，推荐RVSP 2×0.5mm²
- **终端电阻**：总线两端各1个120Ω，1/4W（仅最远端两个节点焊接，中间节点不焊）
- **最大长度**：500kbps速率下≤100米
- **共地**：所有节点CAN收发器GND互连（通过屏蔽层单端接地）

### 4.2 CAN连接器（建议）

阶段一可使用螺丝端子/排针直连，后续阶段统一使用：
- **DB9母头**（标准CAN接口定义）：
  - Pin 2: CAN_L
  - Pin 7: CAN_H
  - Pin 3: GND

## 五、供电方案（阶段一）

```
USB 5V电源适配器 (或PC USB口)
│
├──→ 主站 STM32 板载 5V → 3.3V LDO
│    ├── STM32 (3.3V)
│    ├── OLED (3.3V)
│    └── W5500 (3.3V)
│    └── CAN收发器 (5V, 隔离电源)
│
├──→ 从站 STM32 板载 5V → 3.3V LDO
│    ├── STM32 (3.3V)
│    ├── OLED (3.3V)
│    ├── DHT11 (3.3V)
│    └── CAN收发器 (5V, 隔离电源)
```

> **注意**：主站和从站各自独立供电，通过CAN收发器实现电气隔离。不要共用一个5V电源给两个板子供电（会破坏隔离效果）。

## 七、阶段一新增排线说明

本阶段新增以下独立排线/接口：

| 接口 | 类型 | 线数 | 位置 |
|---|---|---|---|
| OLED_I2C | 4Pin排针 (VCC/GND/SCL/SDA) | 4 | 主站+从站各1组 |
| CAN_Bus | 2Pin螺丝端子 (CAN_H/CAN_L) | 2 | 主站+从站各1组 |
| W5500_SPI | 6Pin排针 (VCC/GND/SCLK/MISO/MOSI/SCS/RST) | 7 | 主站1组 |
| DHT11 | 3Pin排针 (VCC/DATA/GND) | 3 | 从站1组 |
| KEY | 2Pin排针×2 (GPIO/GND) | 2×2 | 从站1组 |
| USART1 | 3Pin排针 (TX/RX/GND) | 3 | 主站+从站各1组 |
