# 阶段一排线设计

> 硬件清单：STM32F103C8T6×3、TJA1050×3、OLED×3、W5500×1、DHT11×1、按键×8、杜邦线、外接5V/3.3V电源×1、面包板×3

## 一、系统整体接线拓扑

```
                    PC (上位机)
              Modbus TCP / ST-Link
                        │
                   ┌────┴────┐
                   │ 以太网   │ ST-Link
                   │ (RJ45)   │ (SWD)
                   │          │
┌──────────────────┴──────────┴───────────────┐
│             主站 (面包板 #1)                  │
│  ┌───────────────────────────────────────┐   │
│  │ STM32F103C8T6        W5500 以太网     │   │
│  │                      OLED(0x78)       │   │
│  │ TJA1050 CAN收发器    [SWD 4P排针]     │   │
│  └───────────────────────────────────────┘   │
└──────────────────────┬──────────────────────┘
                        │ CAN_H / CAN_L (杜邦线)
┌───────────────────────┴──────────────────────┐
│             从站 (面包板 #2)                   │
│  ┌───────────────────────────────────────┐   │
│  │ STM32F103C8T6                         │   │
│  │ OLED(0x78)  DHT11  KEY1 KEY2          │   │
│  │ TJA1050 CAN收发器  [SWD 4P排针]       │   │
│  └───────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

## 二、主站 (Master) 接线

### 2.1 引脚分配表

| STM32引脚 | 连接目标 |
|---|---|
| PC15 | W5500 RST |
| PA4 | W5500 SCS |
| PA5 | W5500 SCLK |
| PA6 | W5500 MISO |
| PA7 | W5500 MOSI |
| PA11 | TJA1050 RXD |
| PA12 | TJA1050 TXD |
| PB8 | OLED SCL |
| PB9 | OLED SDA |

### 2.2 OLED

```
OLED (0.96寸, I2C, 4pin)
  GND → GND
  VCC → 3.3V
  SCL → PB8
  SDA → PB9
```

### 2.3 TJA1050 CAN收发器

```
TJA1050 模块
  VCC  → 5V      (板子5V排针或外接电源)
  GND  → GND
  TXD  → PA12
  RXD  → PA11
  CANH → CAN_H总线 (杜邦线→从站)
  CANL → CAN_L总线 (杜邦线→从站)
```

### 2.4 W5500 以太网模块

```
W5500 模块
  GND  → GND   ← 模块有两个GND引脚，都要接地！
  GND  → GND   ← (第2个GND)
  3.3V → 3.3V  ← 外接独立3.3V，不要从STM32 3.3V排针取电
  SCLK → PA5
  MISO → PA6
  MOSI → PA7
  SCS  → PA4
  RST  → PC15
  INT  → 不接(轮询)
  RJ45 → 网线 → PC
```

### 2.5 ST-Link（烧录/调试）

蓝 Pill 板上有独立的 **4pin SWD 排针**，直接插杜邦线：

```
ST-Link     蓝 Pill SWD排针
  SWDIO  →    SWDIO
  SWCLK  →    SWCLK
  GND    →    GND
  3.3V   →    不接！(板子USB供电, 接3.3V会导致电源对顶、电脑闪屏)
```

> 不需要从 PA13/PA14 飞线，板子已预留 SWD 接口。

## 三、从站 (Slave) 接线

### 3.1 引脚分配表

| STM32引脚 | 连接目标 |
|---|---|
| PA0 | KEY1（故障上报）|
| PA1 | KEY2（故障恢复）|
| PA11 | TJA1050 RXD |
| PA12 | TJA1050 TXD |
| PB8 | OLED SCL |
| PB9 | OLED SDA |
| PB11 | DHT11 DATA |

### 3.2 OLED

```
与主站相同:
  GND→GND, VCC→3.3V, SCL→PB8, SDA→PB9
```

### 3.3 DHT11 温湿度

```
DHT11 (3pin)
  VCC  → 3.3V
  DATA → PB11 (需4.7k上拉, 模块已内置则免)
  GND  → GND
```

### 3.4 按键

```
KEY1: 一端→PA0, 另一端→GND
KEY2: 一端→PA1, 另一端→GND
(PA0/PA1内部上拉, 按下=低电平)
```

### 3.5 TJA1050

```
与主站相同:
  VCC→5V, GND→GND, TXD→PA12, RXD→PA11
  CANH→CAN_H总线, CANL→CAN_L总线
```

### 3.6 ST-Link

同样用板上的 **4pin SWD 排针**，与主站接法相同。

## 四、CAN 总线

```
主站 CAN_H ──── 杜邦线 ──── 从站 CAN_H
主站 CAN_L ──── 杜邦线 ──── 从站 CAN_L
主站 GND   ──── 杜邦线 ──── 从站 GND   (共地必须！)

**为什么 CAN 差分总线也要共地？**
- CAN 收发器（TJA1050）的 CAN_H/CAN_L 共模电压范围是 -7V~+12V，以各自本地 GND 为参考
- 如果主从站 GND 不连通，两端电位差可能漂出共模范围 → 数据错乱或完全不通
- 短距离桌面测试：直接用杜邦线连 GND；长距离工业现场：用屏蔽层或单独地线
```

- 桌面短距离（<30cm）**不接终端电阻**
- 后续拉长线必须配 **120Ω 1/4W 电阻**
- TJA1050 为**非隔离**方案，工业现场需换 ISO1050

## 五、供电

```
外接5V/3.3V电源
  5V  → 主站 5V排针 → TJA1050 VCC
       → 从站 5V排针 → TJA1050 VCC
  3.3V → 主站 3.3V排针 → OLED / W5500
       → 从站 3.3V排针 → OLED / DHT11
  GND  → 主站 GND / 从站 GND
```

或每块蓝 Pill 单独插 USB 供电。
