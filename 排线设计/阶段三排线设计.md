### 4.2 BH1750 光照传感器 ★ 重新引入

> BH1750 在阶段一曾规划但未实现，阶段二被 LM393 替代，最终阶段作为从站 1 的标准传感器重新引入。

```
BH1750 模块 (5pin)
  VCC  → 3.3V
  GND  → GND
  SCL  → PB8  ← 与 OLED SCL 共用！
  SDA  → PB9  ← 与 OLED SDA 共用！
  ADDR → GND  (地址引脚接地 → 7-bit 地址 0x23)
```

#### ⚠️ I2C 总线共享注意事项

BH1750 与 OLED **共用 PB8/PB9 I2C 总线**，两者通过不同设备地址区分：

| 设备 | I2C 地址 | 说明 |
|---|---|---|
| OLED | 0x78 (7-bit) | 写地址 0x78 |
| BH1750 | 0x23 (7-bit) | 写地址 0x46，读地址 0x47 |

> **软件 I2C 驱动**（`bh150.c/h`）使用 GPIO 模拟 I2C 时序（非 STM32 硬件 I2C 外设），因此不存在总线仲裁冲突。但两设备**不可在同一时刻被不同任务访问** —— 本项目设计中 BH1750 读取在 `vTask_Sensor`（优先级 3），OLED 刷新在 `vTask_Housekeep`（优先级 0），FreeRTOS 抢占式调度自然串行化访问。
>
> **如果将来传感器采集频率提高或驱动改为 DMA 模式，需加互斥锁保护 PB8/PB9。**

### 5.2 光敏电阻模块（LM393）

常见 4pin 光敏电阻模块，采用 **LM393 双路比较器**，板载光敏电阻（GL55系列）+ 可调电位器：

```
光敏模块 (4pin)
  VCC → 3.3V
  GND → GND
  DO  → PB0   ← 数字输出（超过阈值=LOW, 低于=HIGH，电位器可调）
  AO  → PB1   ← 模拟输出（0~3.3V，光越强电压越高）
```

#### 模块工作原理

```
         VCC (3.3V)
           │
          ┌┴┐
          │ │  光敏电阻 (GL55: 亮=5~10kΩ, 暗=0.5~1MΩ)
          │ │
          └┬┘
           ├──→ AO (分压点，光越强→阻值越小→电压越高)
           │
          ┌┴┐
          │ │  固定电阻 (10kΩ)
          │ │
          └┬┘
           │
          GND

  AO ──→ LM393 同相输入(+)
         反相输入(-) ← 电位器分压 (阈值电压)
         LM393 输出 → DO (开漏，需上拉)
```

- **光强 ↑** → 光敏电阻值 ↓ → AO 电压 ↑ → ADC 读值 ↑
- **AO 电压 > 阈值** → DO = LOW (亮灯)，反之 DO = HIGH (暗灯)
- DO 为 **开漏输出**，PB0 配置为 **内部上拉（IPU）**，无需外接电阻

#### 电位器调节

| 方向 | 效果 |
|---|---|
| 顺时针拧 | 阈值电压升高 → DO 更难触发 LOW → 需要更大光强 |
| 逆时针拧 | 阈值电压降低 → DO 更容易触发 LOW → 较小光强即触发 |

> 调试建议：在正常室内光照下，缓慢逆时针拧电位器直到 DO LED 刚好熄灭，此时为临界阈值。再逆时针拧 1/8 圈，确保正常光照下 DO=LOW（亮）。

#### 驱动 API（lm393.c / lm393.h）

```c
void     Lm393_Init(void);        // 初始化 PB0(IPU) + PB1(AIN) + ADC1
uint8_t  Lm393_ReadDigital(void); // 读 DO → 0=亮, 1=暗
uint16_t Lm393_ReadAnalog(void);  // 读 AO → ADC 原始值 0~4095
```

### 5.3 预留通道 CH1

Node#02 包含一个**软件层面的预留通道**，目前仅占位：

| 占位项 | 内容 | 说明 |
|---|---|---|
| 传感器表条目 | `sensor_t { .name="CH1", .init_fn=NULL, .read_fn=NULL }` | 占位，不执行任何驱动 |
| CAN 功能码 | `CAN_FUNC_RESERVED (0x07)` | 预留 CAN 通讯点位 |
| sensor_data_t | `reserved.ch1 (uint16_t)` | 预留 2 字节数据字段 |
| OLED 行 | `CH1:----` | 占位显示行 |

后续扩展步骤（接入 4-20mA / 开关量 / 继电器等新传感器）：
1. 编写传感器驱动（`my_sensor.h/c`）
2. 在 `sensor_manager.c` 中编写适配器函数
3. 替换 `#if slave_has_reserved` 代码块中 `NULL` 为适配器函数指针
4. 更新 `main.c` OLED 渲染 `case SENSOR_TYPE_RESERVED` 为实际数据显示
5. **无需修改任何任务代码或 CAN 通信逻辑**

## 七、CAN 总线（不变）

```
主站 CAN_H ──── 杜邦线 ──── 从站 CAN_H
主站 CAN_L ──── 杜邦线 ──── 从站 CAN_L
主站 GND   ──── 杜邦线 ──── 从站 GND   (共地必须！)
```

- 桌面短距离（<30cm）：不接终端电阻
- 长距离：需 120Ω 1/4W 终端电阻
- CAN 差分总线也必须共地（TJA1050 共模电压以本地 GND 为参考）
