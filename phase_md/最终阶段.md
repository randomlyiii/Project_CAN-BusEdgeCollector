# 最终阶段：Config-driven Multi-Variant Slave 固件体系

## 阶段定位

本阶段是 CAN Bus Edge Collector 项目的**最终阶段**，在阶段二（FreeRTOS + 双FIFO + 从站 DHT11/BH1750 采集）已完成的基础上，将从站工程升级为 **单代码仓双变体架构**：通过 snake_case 配置头文件切换从站型号，新增传感器抽象层解耦采集逻辑与任务调度，实现 **一套源码 → 两种从站固件** 的复用目标，并为后续扩展预留占位通道。

本阶段文档对标 `README.md` 第四章（从站采集设计），是前三个阶段的设计收敛与代码落地。

---

## 一、双从站固件总览

根据 README.md 的从站采集业务分层设计（常态任务 1 级 / 低频任务 2 级 / 预留扩展接口），本阶段实现两种从站固件变体：

| 固件变体 | 节点 ID | 传感器组合 | 采集层级 | 用途 |
|---|---|---|---|---|
| **从站 1** (SLAVE_ID=1) | 0x01 | DHT11（温湿度）+ BH1750（光照） | 1 级常态 + 2 级低频 | 环境监测节点 |
| **从站 2** (SLAVE_ID=2) | 0x02 | LM393（光敏 DO/AO）+ **预留通道 1** | 2 级低频 + 预留 | 光敏监测 + 扩展占位 |

### 1.1 从站 1：温湿度 + 光照（继承阶段二配置）

| 项目 | 参数 |
|---|---|
| MCU | STM32F103C8T6 |
| CAN 收发器 | ISO1050 / TJA1050 |
| 显示 | 0.96寸 OLED (I2C, 0x78, PB8/PB9) |
| 传感器 1 | DHT11 (PB11) — 温湿度，1 级常态任务，周期 2s |
| 传感器 2 | BH1750 (I2C1, 0x23, PB8/PB9) — 光照，2 级低频任务，周期 2s |
| 按键 | KEY1=PA0（故障上报）, KEY2=PA1（故障恢复） |
| 调试串口 | USART1 (PA9/PA10, 115200) |

### 1.2 从站 2：光敏监测 + 预留扩展

| 项目 | 参数 |
|---|---|
| MCU | STM32F103C8T6 |
| CAN 收发器 | ISO1050 / TJA1050 |
| 显示 | 0.96寸 OLED (I2C, 0x78, PB8/PB9) |
| 传感器 1 | LM393 光敏模块 — DO（数字亮暗）+ AO（模拟 ADC，0~4095），2 级低频任务，周期 2s |
| **预留通道** | **软件保留 sensor_t 结构体变量 + CAN 通讯点位 + OLED 占位行，不实现采集驱动** |
| 按键 | KEY1=PA0, KEY2=PA1 |
| 调试串口 | USART1 (PA9/PA10, 115200) |

## 二、核心复用策略

### 2.1 为什么需要复用架构

阶段二从站存在以下复用障碍：

1. **节点地址硬编码**：`SLAVE_NODE_ID 0x01` 写在 `CAN_User.h` 中，换节点必须改源码
2. **传感器硬耦合**：`Task_Sensor()` 在 main.c 中直接调 `DHT11_Read_Data()` / `BH1750_Read()`，增减传感器需改任务代码
3. **CAN 帧构建硬编码**：`CAN_SendTempHumi()` / `CAN_SendLight()` 各自独立，新增传感器需新增帧函数
4. **OLED 显示硬编码**：`OLED_UpdateDisplay()` 直接引用 `g_temp_int` / `g_light_lux`，传感器变化需重写整行
5. **全量编译**：所有传感器驱动均参与编译，即使未使用也占用 Flash/RAM

### 2.2 复用原则

| 原则 | 说明 |
|---|---|
| **配置驱动** | 所有差异点（节点ID、传感器列表、CAN 参数）由配置头文件定义 |
| **snake_case** | 新架构层（配置宏/全局变量/管理函数）统一使用 snake_case 命名 |
| **向后兼容** | 底层硬件驱动 (dht11.c/bh150.c/lm393.c) 接口不变，不改已有代码 |
| **零运行时开销** | 传感器表由 `#if` 条件编译展开，未启用的传感器不在表中 |
| **增量迁移** | 阶段二代码可直接运行于阶段三框架，无需修改 |

### 2.3 对标 README.md 设计

| README 设计项 | 最终阶段实现 |
|---|---|
| 采集业务分层（1级常态/2级低频） | `sensor_t.priority` 字段 + 双 CAN ID 基址 |
| 预留扩展接口（4-20mA/开关量/继电器） | `slave_has_reserved` 配置宏 + `SENSOR_TYPE_RESERVED` 占位 |
| 本地缓存容错 | 保留阶段二 `LocalCache` 双 FIFO，不变 |
| 按键故障上报/恢复 | 保留阶段二 KEY1/KEY2 逻辑，不变 |

### 5.1 传感器类型枚举

```c
#define SENSOR_TYPE_RESERVED    0x05   /* 预留通道（占位，无驱动） */

/* 传感器优先级 */
#define SENSOR_PRIOR_NORMAL     1      /* 1级常态任务 */
#define SENSOR_PRIOR_LOWFREQ    2      /* 2级低频任务 */
```

### 5.2 传感器数据联合体

**`Hardware/sensor_manager.h`**：

```c
#ifndef __SENSOR_MANAGER_H
#define __SENSOR_MANAGER_H

#include "stm32f10x.h"
#include "FreeRTOS.h"
#include "../Config/sensor_type.h"
#include <string.h>

/* ---- 传感器数据联合 ---- */
typedef union {
    struct {
        uint8_t temp_int;
        uint8_t temp_dec;
        uint8_t humi_int;
        uint8_t humi_dec;
    } dht11;
    struct {
        uint16_t lux;
    } bh1750;
    struct {
        uint8_t  digital;   /* DO: 0=bright, 1=dark */
        uint16_t analog;    /* AO: raw ADC 0~4095 */
    } lm393;
    struct {
        uint16_t ch1;       /* 预留通道 1 数据 */
    } reserved;
    uint8_t raw[8];          /* 兼容 CAN 8 字节帧载荷 */
} sensor_data_t;

/* ---- 传感器描述符 ---- */
typedef struct {
    /* 静态配置 */
    const char      name[12];           /* 人类可读名 */
    uint8_t         type_id;            /* SENSOR_TYPE_* */
    uint8_t         priority;           /* SENSOR_PRIOR_NORMAL / LOWFREQ */
    uint16_t        interval_ms;        /* 采样间隔 */
    uint8_t       (*init_fn)(void);     /* 初始化函数, 返回0=OK; NULL=无驱动 */
    uint8_t       (*read_fn)(sensor_data_t *out); /* 读取函数, NULL=无驱动 */
    uint8_t         enabled;            /* 1=启用, 0=禁用 */

    /* 运行时状态 */
    uint8_t         online;             /* 0=离线/故障, 1=在线 */
    uint8_t         fault_count;        /* 连续失败次数 */
    uint8_t         alarm_active;       /* 1=已发报警, 恢复后要发RECOVER */
    TickType_t      last_read_tick;     /* 上次读取时刻 */
    sensor_data_t   last_data;          /* 最近一次成功读值 */
} sensor_t;

/* ---- API ---- */
uint8_t     sensor_manager_init(void);              /* 初始化所有已启用传感器 */
uint8_t     sensor_manager_get_count(void);          /* 获取启用传感器数量 */
sensor_t   *sensor_manager_get_by_index(uint8_t idx);/* 按索引获取 */
sensor_t   *sensor_manager_get_by_type(uint8_t id);  /* 按类型获取 */
void        sensor_manager_read_all(void);           /* 轮询所有传感器 */
uint8_t     sensor_manager_has_alarm(void);          /* 是否有传感器报警 */

#endif /* __SENSOR_MANAGER_H */
```

### 5.3 传感器表：条件编译展开

**`Hardware/sensor_manager.c`**：

```c
#include "sensor_manager.h"
#include "dht11.h"
#include "bh150.h"
#include "lm393.h"

/* ---- 传感器驱动适配器（将不同驱动统一到 read_fn 签名） ---- */

#if slave_has_dht11
static uint8_t dht11_adapter_init(void)
{
    DHT11_GPIO_Init();
    return 0;
}
static uint8_t dht11_adapter_read(sensor_data_t *out)
{
    return DHT11_Read_Data(&out->dht11.humi_int, &out->dht11.humi_dec,
                           &out->dht11.temp_int, &out->dht11.temp_dec);
}
#endif

#if slave_has_bh1750
static uint8_t bh1750_adapter_init(void)
{
    BH1750_Init();
    return 0;
}
static uint8_t bh1750_adapter_read(sensor_data_t *out)
{
    return BH1750_Read(&out->bh1750.lux);
}
#endif

#if slave_has_lm393
static uint8_t lm393_adapter_init(void)
{
    Lm393_Init();
    return 0;
}
static uint8_t lm393_adapter_read(sensor_data_t *out)
{
    out->lm393.digital = Lm393_ReadDigital();
    out->lm393.analog  = Lm393_ReadAnalog();
    return 0;
}
#endif

/* 预留通道：无驱动函数指针，init_fn/read_fn 置 NULL */

/* ---- 传感器表 -- 条件编译展开，未启用的传感器不占空间 ---- */

static sensor_t g_sensor_table[] = {
#if slave_has_dht11
    {
        .name        = "DHT11",
        .type_id     = SENSOR_TYPE_DHT11,
        .priority    = SENSOR_PRIOR_NORMAL,
        .interval_ms = sensor_dht11_interval_ms,
        .init_fn     = dht11_adapter_init,
        .read_fn     = dht11_adapter_read,
        .enabled     = 1,
    },
#endif
#if slave_has_bh1750
    {
        .name        = "BH1750",
        .type_id     = SENSOR_TYPE_BH1750,
        .priority    = SENSOR_PRIOR_LOWFREQ,
        .interval_ms = sensor_bh1750_interval_ms,
        .init_fn     = bh1750_adapter_init,
        .read_fn     = bh1750_adapter_read,
        .enabled     = 1,
    },
#endif
#if slave_has_lm393
    {
        .name        = "LM393",
        .type_id     = SENSOR_TYPE_LM393_AO,
        .priority    = SENSOR_PRIOR_LOWFREQ,
        .interval_ms = sensor_lm393_interval_ms,
        .init_fn     = lm393_adapter_init,
        .read_fn     = lm393_adapter_read,
        .enabled     = 1,
    },
#endif
#if slave_has_reserved
    {
        .name        = sensor_reserved_name,   /* "CH1" */
        .type_id     = SENSOR_TYPE_RESERVED,
        .priority    = sensor_reserved_priority,
        .interval_ms = sensor_reserved_interval_ms,
        .init_fn     = NULL,                   /* 无驱动 */
        .read_fn     = NULL,                   /* 无驱动 */
        .enabled     = 1,
    },
#endif
};

#define SENSOR_COUNT  (sizeof(g_sensor_table) / sizeof(g_sensor_table[0]))

/* ---- API 实现 ---- */

uint8_t sensor_manager_init(void)
{
    uint8_t all_ok = 1;
    for (uint8_t i = 0; i < SENSOR_COUNT; i++) {
        if (g_sensor_table[i].init_fn) {
            if (g_sensor_table[i].init_fn() != 0) {
                g_sensor_table[i].online = 0;
                all_ok = 0;
            } else {
                g_sensor_table[i].online = 1;
            }
        } else {
            /* 无驱动传感器（预留通道）默认 online=1 */
            g_sensor_table[i].online = 1;
        }
    }
    return all_ok;
}

uint8_t sensor_manager_get_count(void)
{
    return SENSOR_COUNT;
}

sensor_t *sensor_manager_get_by_index(uint8_t idx)
{
    if (idx >= SENSOR_COUNT) return NULL;
    return &g_sensor_table[idx];
}

sensor_t *sensor_manager_get_by_type(uint8_t id)
{
    for (uint8_t i = 0; i < SENSOR_COUNT; i++) {
        if (g_sensor_table[i].type_id == id)
            return &g_sensor_table[i];
    }
    return NULL;
}

void sensor_manager_read_all(void)
{
    TickType_t now = xTaskGetTickCount();

    for (uint8_t i = 0; i < SENSOR_COUNT; i++) {
        sensor_t *s = &g_sensor_table[i];
        if (!s->enabled) continue;

        /* 检查采样间隔 */
        if ((now - s->last_read_tick) < pdMS_TO_TICKS(s->interval_ms))
            continue;

        s->last_read_tick = now;

        /* 无驱动传感器（预留通道）：不执行读取，仅更新时间戳 */
        if (!s->read_fn) {
            s->online = 1;
            continue;
        }

        /* 执行读取 */
        sensor_data_t data;
        if (s->read_fn(&data) == 0) {
            s->last_data = data;
            s->online = 1;
            s->fault_count = 0;
            if (s->alarm_active) {
                s->alarm_active = 0;
            }
        } else {
            s->fault_count++;
            if (s->fault_count >= 3 && !s->alarm_active) {
                s->alarm_active = 1;
            }
        }
    }
}

uint8_t sensor_manager_has_alarm(void)
{
    for (uint8_t i = 0; i < SENSOR_COUNT; i++) {
        if (g_sensor_table[i].alarm_active)
            return 1;
    }
    return 0;
}
```

### 5.4 适配器模式说明

底层驱动（DHT11/BH1750/LM393）接口**保持不变**，通过薄适配器函数桥接到 `sensor_t` 统一接口：

```
底层驱动接口                    适配器函数          传感器管理
───────────────────────────────────────────────────────────
DHT11_Read_Data(&h,&hd,&t,&td)  → dht11_adapter_read()  → sensor_t.read_fn
BH1750_Read(&lux)               → bh1750_adapter_read() → sensor_t.read_fn
Lm393_ReadDigital() + Analog()  → lm393_adapter_read()  → sensor_t.read_fn
```

优势：
- 底层驱动零改动，降低回归风险
- 适配器可封装脏数据校验、量程转换等
- 新增传感器只需：①写驱动 + ②写适配器 + ③加到传感器表

### 5.5 预留通道设计规范

从站 2 的预留通道遵循以下规则：

| 规则 | 说明 |
|---|---|
| **结构体保留** | `sensor_data_t` 中包含 `reserved.ch1` 字段（uint16） |
| **通讯点位保留** | `SENSOR_TYPE_RESERVED` 枚举 + CAN 通用帧构建器对应 case 分支 |
| **函数指针置 NULL** | `init_fn = NULL, read_fn = NULL`，驱动不实现 |
| **OLED 占位** | OLED 渲染器中预留 `CH1:----` 显示行 |
| **`slave_has_reserved` 开关** | 编译开关，从站 2 使能，从站 1 关闭 |

后续扩展步骤：
1. 编写传感器驱动（如 4-20mA 模拟量采集）
2. 编写适配器函数

## 六、CAN 通信层重构

### 6.1 通用帧构建器

阶段二为每种传感器写了独立发送函数。最终阶段合并为通用构建器，由 `sensor_type_id` 驱动：

```c
/* CAN_User.h — 新增 */
void CAN_SendSensorData(uint8_t sensor_type_id, sensor_data_t *data);
void CAN_SendHeartBeat(void);            /* 保留 */
void CAN_SendAlarm(void);                /* 保留 */
void CAN_SendRecover(void);              /* 保留 */
```

**`CAN_User.c` — 新增实现**：

```c
/* CAN ID 基址映射表 */
static uint32_t SensorTypeToCanId(uint8_t type_id)
{
    switch (type_id) {
    case SENSOR_TYPE_DHT11:
        return CAN_ID_NORMAL_BASE + slave_node_id + slave_can_id_offset;
    case SENSOR_TYPE_BH1750:
    case SENSOR_TYPE_LM393_AO:
    case SENSOR_TYPE_RESERVED:
        return CAN_ID_LOWFREQ_BASE + slave_node_id + slave_can_id_offset;
    default:
        return CAN_ID_NORMAL_BASE + slave_node_id + slave_can_id_offset;
    }
}

/* CAN 功能码映射表 */
static uint8_t SensorTypeToFunc(uint8_t type_id)
{
    switch (type_id) {
    case SENSOR_TYPE_DHT11:     return CAN_FUNC_TEMP_HUMI;
    case SENSOR_TYPE_BH1750:    return CAN_FUNC_LIGHT;
    case SENSOR_TYPE_LM393_AO:  return CAN_FUNC_LIGHT;
    case SENSOR_TYPE_LM393_DO:  return 0x06;
    case SENSOR_TYPE_RESERVED:  return 0x07;   /* 新增：预留通道 */
    default:                    return 0xFF;
    }
}

void CAN_SendSensorData(uint8_t sensor_type_id, sensor_data_t *data)
{
    uint32_t id   = SensorTypeToCanId(sensor_type_id);
    uint8_t  func = SensorTypeToFunc(sensor_type_id);
    uint8_t  payload_len = 4;

    uint8_t payload[4] = {0, 0, 0, 0};

    switch (sensor_type_id) {
    case SENSOR_TYPE_DHT11:
        payload[0] = data->dht11.temp_int;
        payload[1] = data->dht11.temp_dec;
        payload[2] = data->dht11.humi_int;
        payload[3] = data->dht11.humi_dec;
        break;
    case SENSOR_TYPE_BH1750:
        payload[0] = (uint8_t)(data->bh1750.lux >> 8);
        payload[1] = (uint8_t)(data->bh1750.lux & 0xFF);
        break;
    case SENSOR_TYPE_LM393_AO:
        payload[0] = (uint8_t)(data->lm393.analog >> 8);
        payload[1] = (uint8_t)(data->lm393.analog & 0xFF);
        payload[2] = data->lm393.digital;
        break;
    case SENSOR_TYPE_RESERVED:
        payload[0] = (uint8_t)(data->reserved.ch1 >> 8);
        payload[1] = (uint8_t)(data->reserved.ch1 & 0xFF);
        break;
    default:
        break;
    }

    SendCANData(id, func, payload, payload_len);
}
```

### 6.2 CAN 功能码扩展

| 功能码 | 宏名 | 数据来源 | 说明 |
|---|---|---|---|
| 0x01 | `CAN_FUNC_HEARTBEAT` | — | 心跳（不变） |
| 0x02 | `CAN_FUNC_TEMP_HUMI` | DHT11 | 温湿度（不变） |
| 0x03 | `CAN_FUNC_ALARM` | — | 报警（不变） |
| 0x04 | `CAN_FUNC_RECOVER` | — | 恢复（不变） |
| 0x05 | `CAN_FUNC_LIGHT` | BH1750 / LM393 | 光照（不变，扩展数据源） |
| 0x06 | `CAN_FUNC_LM393_DO` | LM393 DO | **新增**：数字光敏独立上报 |
| 0x07 | `CAN_FUNC_RESERVED` | 预留通道 | **新增**：预留通道功能码 |

### 6.3 CAN ID 分配

| 帧类型 | ID 基址 | 说明 |
|---|---|---|
| 0 级紧急帧 | 0x100 + slave_node_id + offset | 报警/故障上报 |

```c
static void oled_render_node_info(char *buf, uint16_t size)
{
    const char *status = sensor_manager_has_alarm() ? "ALARM" : "Ready";
    snprintf(buf, size, "S:%s %s", slave_node_name_str, status);
}

static void oled_render_sensor_data(char *buf, uint16_t size, uint8_t idx)
{
    sensor_t *s = sensor_manager_get_by_index(idx);
    if (!s || !s->online) {
        snprintf(buf, size, "%s:OFFLINE", s ? s->name : "?");
        return;
    }

    switch (s->type_id) {
    case SENSOR_TYPE_DHT11:
        snprintf(buf, size, "T:%u.%uC H:%u.%u%%",
                 s->last_data.dht11.temp_int,
                 s->last_data.dht11.temp_dec,
                 s->last_data.dht11.humi_int,
                 s->last_data.dht11.humi_dec);
        break;
    case SENSOR_TYPE_BH1750: {
        uint16_t lux = s->last_data.bh1750.lux;
        if (lux < 1000)
            snprintf(buf, size, "Lux:%4u   ", lux);
        else
            snprintf(buf, size, "Lux:%u.%uk ", lux/1000, (lux%1000)/100);
        break;
    }
    case SENSOR_TYPE_LM393_AO:
        snprintf(buf, size, "Photo DO:%s A:%4u",
                 s->last_data.lm393.digital ? "DK" : "BR",
                 s->last_data.lm393.analog);
        break;
    case SENSOR_TYPE_RESERVED:
        snprintf(buf, size, "CH1:----   ");  /* 占位显示 */
        break;
    default:
        snprintf(buf, size, "%s:---", s->name);
        break;
    }
}

static void oled_render_can_status(char *buf, uint16_t size)
{
    const char *can_state = LocalCache_IsOffline(&g_local_cache) ? "OFF" : "OK";
    uint8_t cache_cnt = LocalCache_Count(&g_local_cache);
    uint32_t tx = g_can_tx_oled_count;
    if (tx > 99999) tx = 99999;

    snprintf(buf, size, "TX:%05lu C:%02u/%-2u",
             (unsigned long)tx, cache_cnt, LOCAL_CACHE_MAX);
}
```

## 八、FreeRTOS 任务重构

### 8.1 新任务架构

```
vTask_Sensor (优先级 3)
  └─ sensor_manager_read_all()                    ← 表驱动，遍历所有传感器
      ├─ [DHT11] 按 interval 采样 → 更新 online/fault_count
      ├─ [BH1750] 按 interval 采样 → 同上
      ├─ [LM393] 按 interval 采样 → 同上
      └─ [预留]   无驱动 → 仅更新时间戳

vTask_CAN_Slave (优先级 2)
  ├─ CAN_SendHeartBeat()                           ← 心跳
  ├─ 遍历传感器表：online 且到采样周期的传感器 → CAN_SendSensorData()
  ├─ 传感器 alarm_active → CAN_SendAlarm()
  ├─ 传感器故障恢复 → CAN_SendRecover()
  └─ LocalCache_ShouldReplay() → 补传缓存帧

vTask_Key (优先级 1)
  └─ 不变

vTask_Housekeep (优先级 0)
  ├─ IWDG 喂狗
  ├─ 栈水位检测（不变）
  └─ OLED_UpdateDisplay()                         ← 表驱动
```

### 8.2 vTask_Sensor 新实现

```c
static void Task_Sensor(void *pvParameters)
{
    TickType_t xLastWakeTime = xTaskGetTickCount();
    (void)pvParameters;

    for (;;) {
        /* 一次调用处理所有传感器（内部按 interval 判断是否采样） */
        sensor_manager_read_all();

        vTaskDelayUntil(&xLastWakeTime, pdMS_TO_TICKS(200));
    }
}
```

> 扫描周期从 2000ms 降至 **200ms**，因为 `sensor_manager_read_all()` 内部用 `last_read_tick` 控制各传感器实际采样间隔。

### 8.3 vTask_CAN_Slave 新实现

```c
static void Task_CAN_Slave(void *pvParameters)
{
    TickType_t xLastWakeTime = xTaskGetTickCount();
    (void)pvParameters;

    for (;;) {
        /* 心跳 */
        CAN_SendHeartBeat();
        g_can_tx_oled_count++;

        /* 遍历传感器，发送到期的传感器数据 */
        for (uint8_t i = 0; i < sensor_manager_get_count(); i++) {
            sensor_t *s = sensor_manager_get_by_index(i);
            if (!s->online || !s->enabled) continue;
            if (!s->read_fn) continue;  /* 跳过无驱动传感器 */

            if (CAN_SendSensorData(s->type_id, &s->last_data) == 0)
                g_can_tx_oled_count++;

            if (s->alarm_active && s->fault_count >= 3) {
                CAN_SendAlarm();
                g_can_tx_oled_count++;
            }

            if (s->online && !s->alarm_active) {
                /* recover_pending 标记由 sensor_manager_read_all 设置 */
            }
        }

        /* 缓存补传（不变） */
        if (LocalCache_ShouldReplay(&g_local_cache)) {
            uint32_t id;
            uint8_t  data[CAN_DATA_LEN];
            if (LocalCache_Pop(&g_local_cache, &id, data) == 0) {
                CAN_SendFrame(id, data, 8);
                g_can_tx_oled_count++;
            }
        }

        vTaskDelayUntil(&xLastWakeTime, pdMS_TO_TICKS(500));
    }
}
```

```
SLAVE_NODE_ID 硬编码         slave_node_id 从 config 读
直接调用 DHT11/BH1750       sensor_manager 表驱动
传感器独立全局变量           sensor_t.last_data 统一存储
CAN_SendTempHumi/Light     CAN_SendSensorData(type_id, data)
OLED 四行硬编码              4x 行渲染器 ∥ 传感器表
新增从站: 复制工程+改代码    新增从站: 写 .h 配置 + 适配器
LM393 单独开发              LM393 由配置驱动 + 预留通道占位
```

> **最终阶段不改变**：FreeRTOS 任务优先级/栈深度、CAN 应用层协议（帧 ID 分配/功能码）、OLED 4×16 硬件限制、I2C 引脚分配、KEY 引脚定义。所有变更是**源码级复用升级**，而非推翻重来。

## 十五、踩坑预判

| # | 预判风险点 | 预防措施 |
|---|---|---|
| 1 | 阶段二全局变量在 main.c 中被多处引用，删除后编译失败 | 分步迁移：先新增 sensor_manager，旧全局变量转为接口桥接，确认无误后删除 |
| 2 | `slave_node_id` 与阶段二 `SLAVE_NODE_ID` 混用造成混淆 | 过渡期共存，新增代码用 `slave_node_id`，旧代码逐步迁移 |
| 3 | `sensor_manager_read_all()` 在 200ms 循环内，`#if` 展开的传感器表循环耗时不可控 | 传感器数量上限设为 4（STM32F103C8 够用），超限编译期断言 |
| 4 | OLED 行渲染器用 `snprintf` + sensor_t.name 字符串 → 栈空间增加 | `snprintf` 目的缓冲仅 17 字节，栈无额外压力 |
| 5 | `CAN_SendSensorData()` 内 switch-case 耗时 > CAN 发送时间窗 | case 分支仅赋值 4 字节，微秒级，不影响 CAN 发送 |
| 6 | LM393 与 BH1750 共用 `CAN_FUNC_LIGHT`，主站无法区分 | 新增 `CAN_FUNC_LM393_DO (0x06)` 区分，主站按 0x06 识别 LM393 |
| 7 | 条件编译 `#if slave_has_dht11` 未定义视为 false，新增配置如忘定义宏则传感器静默不编译 | `slave_config.h` 底部加 `#ifndef slave_has_dht11` 默认值 |
| 8 | 预留通道 init_fn/read_fn 为 NULL，调用前未检查 → HardFault | `sensor_manager_init()` 和 `vTask_CAN_Slave` 中判断函数指针非 NULL 再调用 |
