## 一、CAN总线报文分级与升降级机制
### 报文优先级定义
0-紧急任务帧：急停、设备过温/过流报警、传感器断线、从站人工故障上报
1-常态任务帧：周期温湿度采集、节点心跳报文
2-低频任务帧：光敏采集、设备参数读取
### 升降级规则
1. 触发升级条件：传感器超限、采集硬件故障、CAN底层报错时，1/2级报文临时升级为0级紧急帧；总线负载＞90%时禁止普通报文升级，防止挤占紧急通道。
2. 降级机制：升级报文内置500ms超时计时器，超时无故障清除自动切回原优先级；按键上报故障恢复可立即强制降级。

## 二、双FIFO缓冲架构（消除并发冲突+溢出保护）
1. 缓冲分区
- FIFO_HIGH：0级紧急报文专用，深度16帧；
- FIFO_NORMAL：1/2级常态+低频报文共用，深度64帧；
2. 溢出处置策略
- FIFO_HIGH溢出：丢弃最旧紧急帧，记录故障日志上传上位机；
- FIFO_NORMAL溢出：优先丢弃最新2级低频光敏数据，保留1级心跳/温湿度；缓存全满则丢弃旧常态帧；
3. 并发保护：两级FIFO读写、总线负载、故障状态全局变量全部加FreeRTOS互斥锁保护。

## 三、STM32主站设计（W5500硬件TCP/IP以太网）
### 核心功能
1. CAN总线负载率实时管控
    - 100ms滑动窗口高精度计算总线负载；
    - 负载＜70%：全量报文正常上报；
    - 70% ≤ 负载＜90%：低频光敏上报周期翻倍限流；
    - 负载≥90%：暂停所有非0级报文，仅放行紧急报警、心跳。
2. 节点心跳自愈与故障检测
    - 心跳周期500ms，连续3次丢失判定节点离线；
    - 离线节点加入黑名单屏蔽10s，到期自动握手恢复；
    - 从站KEY1故障上报可临时标记故障节点，KEY2恢复指令提前解除屏蔽。
3. CAN错误状态机全流程管理
    - 实时统计TEC/REC收发错误计数；
    - 主动错误：仅日志记录；被动错误：全局限流降频；总线关闭：自动复位CAN外设、清空FIFO并上报紧急故障。
4. CAN-Modbus TCP协议双向转换
    - 转换缓存分实时区+历史区，历史缓存上限100条，超量自动丢弃旧数据；
    - 网络短断网（＜3s）保留缓存，恢复后批量上传；长断网（＞3s）清空低频历史数据，仅留存紧急故障帧；
    - 支持多Modbus TCP客户端并发连接，内置自动重连机制。

### FreeRTOS任务优先级分配（数字越大优先级越高）
1. 优先级1：CAN硬件收发处理（底层硬件最高优先级）
2. 优先级2：总线状态、负载率、错误状态轮询检测
3. 优先级3：CAN报文解析、数据校验、协议打包
4. 优先级4：W5500以太网Modbus TCP转发
5. 优先级0（后台低优先级）：看门狗喂狗、故障日志存储、内存监控、系统参数存储

## 四、STM32从站采集设计
1. 采集业务分层
    - 常态任务(1级)：周期温湿度数据采集；
    - 低频任务(2级)：光敏传感器数据采集；
    - 预留扩展接口：4-20mA模拟量、开关量输入、继电器输出。
2. 本地故障主动上报按键
    - KEY1：检测到传感器断线/数值超限，主动发送0级紧急故障帧至主站；
    - KEY2：故障排除，发送恢复报文，通知主站解除节点故障标记；
3. 本地缓存容错：CAN通信异常时本地缓存采集数据，通信恢复后补传历史数据。
